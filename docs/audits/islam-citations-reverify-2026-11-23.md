# Islam tab — citations re-verified against the primary source pages

*2026-11-23. Scope (frozen): citations only, on `worldviews.html` (Islam section, lines 326–1883) and
`library/islam-{jesusmuslim,jesus,prophecy,sira,hadith,naskh,qiraat,science,wahy,eternalword,tawhid}.html`.
No argument was rewritten.*

**Why this pass exists.** The 2026-11-22/23 cloud session that reviewed and extended these twelve files could not
reach sunnah.com, quran.com, biblegateway.com or newadvent.org, so most wording and several numbers and gradings
were checked from search-result snippets or memory, and the `content-review` stamps say so. This session had open
web access and opened the pages.

**Method.** Every row below was checked against a page actually fetched in this session; nothing is marked
VERIFIED from memory. Hadith: the sunnah.com page for each number (English, Arabic where it mattered, and the
grading table). Qur'an: quran.com's own data service (`api.quran.com`, translation 20 = Saheeh International,
plus the Uthmani Arabic) and, where an edition difference appeared, `corpus.quran.com`. Bible: biblegateway.com,
ESV (and NKJV / NIV where a card quotes those). Athanasius: newadvent.org. The quoted strings on the pages were
also compared to the fetched text by script (whitespace, diacritics and punctuation normalised), so a dropped or
changed word shows up mechanically. Tafsir, variant-reading, grading and modern-scholarship rows were checked by
two read-only `apologia-citations` agents with web access; their rows are marked **(agent)** and carry the URL the
agent opened.

**Verdicts.** VERIFIED = the page says what we say. ERROR = the page says something different (fixed; see §7).
STILL UNVERIFIED = no page that settles it could be opened. A "note" on a VERIFIED row records a difference that
is not an error (an omitted translator's gloss, a different edition of the same translation).
